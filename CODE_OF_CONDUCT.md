# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1, in spirit — short version below, because this is a small
documentation repo and common sense mostly suffices.

## The short version

- Be respectful and constructive. Critique ideas, commands, and methodology —
  never people.
- Welcome newcomers. Everyone was confused by `vmstat` output once.
- No harassment, no personal attacks, no publishing others' private
  information.
- Assume good faith; disagree with evidence. In this repo especially, "show
  me the measurement" is a friendly sentence.

## Scope

Applies to all project spaces (issues, PRs, discussions) and to representing
the project in public.

## Enforcement

Report unacceptable behavior by opening a private channel with the maintainer
(GitHub: [@thecsdoctor](https://github.com/thecsdoctor)). Reports are handled
confidentially. Maintainers may remove, edit, or reject comments, commits,
and contributions that violate this code, and may ban contributors for
inappropriate, threatening, or harmful behavior.

For the full text, see
https://www.contributor-covenant.org/version/2/1/code_of_conduct.html
